## Revised problem and boundaries

A narrowly testable *evaluation question*, not a method claim:

> When a scorer receives an incomplete set of reference meanings for a language-specified physical predicate, can exact physical interventions expose discrepancies between the reported error envelope and the controlled latent intended meaning, and does this change how real NL-to-formal methods rank?

The **last clause is untested**. Any value beyond prior work requires independently justified semantic annotations, actual NLP/ML outputs, fair matched-information baselines and held-out results.

### Identifiability boundary

For instruction i, let Y_i denote its independently determined intended predicate, C_i the candidate formalization, and S_i a supplied reference set. Let e_i(C,R) indicate whether C and R disagree on any reachable physical state. The observed finite-sample envelope is:

L_S = (1/n) sum_i min_{R in S_i} e_i(C_i,R)
U_S = (1/n) sum_i max_{R in S_i} e_i(C_i,R).

If Y_i belongs to S_i for every i, then L_S <= (1/n)sum_i e_i(C_i,Y_i) <= U_S. If a Y_i is omitted, **that containment is not guaranteed**. This is elementary arithmetic and an assumption check, NOT a new theorem or population-level statistical guarantee. A physical verifier can check disagreement between *specified* predicates but cannot infer the intended human meaning from physics alone.

## New exact physical-family control

The previous reflecting-particle oracle uses a one-step piecewise-affine reflection on a restricted domain. We added a genuinely different (but equally elementary) **two-step damped-motion** oracle:

v_(t+1) = rho*v_t + u_t, x_(t+1) = x_t + v_(t+1), 0 <= rho <= 1.

Consequently x_2 = x_0 + (rho+rho^2)*v_0 + (1+rho)*u_0 + u_1. With rational independent box inputs, all coefficients are nonnegative, so its reachable interval and separating witnesses are exact rationals. No numerical integration, statistical fitting, or learning is involved.

## Explicit falsification and publication gates

- **Prior-art kill:** If a benchmark already measures reference-set omission under independently specified physical interventions and equivalent scoring assumptions, do not claim a new benchmark.
- **Measurement kill:** If actual latent meanings cannot be justified independently of the scorer or if templates leak the intended formula, do not claim semantic accuracy or model ranking.
- **Fairness kill:** A baseline given one reference cannot be compared as if it had the same information as a method given the latent truth. Report each oracle-access tier separately.
- **Generalization kill:** If findings vanish under held-out dynamics, paraphrase families or non-synthetic human descriptions, reject generalization.
- **Scientific kill:** A ten-case constructed fixture, a few exact equations, and green CI are not enough for a research paper.
- **ML/NLP requirement:** Real learned-model evaluations remain outstanding. The present suite has *zero* model predictions.
- **Physics limitation:** Two toy dynamics families do not validate physical realism.
- **No fabrication:** Do not invent model runs, human annotations, peer review, paper acceptance or novel theorems.
