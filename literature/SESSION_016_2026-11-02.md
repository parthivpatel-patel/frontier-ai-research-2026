The two pre-registered interventions had no opportunity to change a parsed answer: no compact inequality candidates or multi-marker responses were found. The 18 no-marker rows use the same fallback under both rules. The four Claude rows with duplicate parsed relations are not automatically errors: the published scorer intentionally compares **sets**, and duplicates cannot affect that set-equality score.

**Do not overinterpret:** This null result does not establish that the parser is universally robust, that every model answer is correct, that the dataset has no annotation problems, or that no other *pre-specified* parser could change a score. The input is a fixed, upstream-attributed historical collection; model provenance and reference truth are not independently verified. Model versions and repeat counts differ, so the scores must not be presented as a controlled model ranking.

## Theoretical guardrail for the main paper

For a fixed pair of formal interpretations `phi` and `psi` and a declared set of physically admissible traces `D`, define the disagreement witness indicator

`W(D) = 1` iff there exists a trace `tau in D` with `phi(tau) != psi(tau)`.

If `D_small` is a subset of `D_large`, then `W(D_small) <= W(D_large)`: shrinking the admissible trace set cannot create a disagreement witness, and can mask an existing one. This is an elementary consequence of set inclusion, **not a novel theorem**. It does not establish which interpretation a human intended. This distinction must be central in any future experimental design.
