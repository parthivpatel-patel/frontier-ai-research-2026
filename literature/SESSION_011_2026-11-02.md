### Exact toy comparison
All results use **one original external instruction**, with four distinct modified offsets {1,2,4,6}. Neither four offsets nor five mutation rows represent independent human instructions. `a` means state 0; `b` means state 2; initial state 0. Source formula: `G(a -> X^3 b)`.

| Toy model | Source true, changed false | Source false, changed true | Completeness |
| --- | --- | --- | --- |
| Flexible bounded actuator: state changes by at most one | Witnesses for **4/4** offsets | Witnesses for **3/4** offsets (2,4,6) | **Bounded** lasso search; absence is not equivalence |
| Fixed positive-step actuator: 0,1,2,2,... | Witness for **1/4** offsets (1) | **0/4** | **Exhaustive**, because exactly one infinite trace exists |

The absence of a reverse witness for offset 1 in the flexible model has an independent one-step reachability argument: initial `a` holds at state 0, while `b` at state 2 is unreachable after one bounded step. The fixed model has exact dynamics-restricted equivalence for offsets 2,4,6 **on that model only**. These are elementary classical finite-state facts, not novel theorems.

A deliberately impossible logical witness with a state jump 0 -> 2 is rejected. Bounded search non-detection is explicitly labelled as **not** a proof of equivalence. All witnesses are infinite ultimately periodic traces, not truncated finite traces.

**Interpretation:** whether a logical mismatch matters depends on the specified admissible dynamics. This is a controlled methodological demonstration, **not a real physics experiment, NLP performance measurement, or publication-grade statistical result**.

## Critical literature audit: the proposed broad contribution is already covered
A stronger pre-existing benchmark surfaced today:
- **English et al., 2025-07-01**, *Verifiable Natural Language to Linear Temporal Logic Translation: A Benchmark Dataset and Evaluation Suite* (VLTL-Bench), https://arxiv.org/abs/2507.00877 . It already uses **four distinct state spaces**, sample traces, and grounding/verification evaluation for NL-to-LTL. Therefore, simply claiming to introduce state-space-grounded semantic verification is **not novel**.
- **English et al., 2025-12-18**, *GinSign*, https://arxiv.org/abs/2512.16770 . It already studies mapping language atoms into system signatures and downstream semantic equivalence.
- **Quansah & Bonnah, 2026-05-20**, *NeuroNL2LTL*, https://arxiv.org/abs/2605.22874 . It already combines learned translation and formal verification in a training loop. Reported performance is the authors' claim, not reproduced here.
- **Hou et al., 2026-08-28**, *Linear Temporal Logic Translation via Human-Inspired Self-Constrained Reasoning for Robot Task Specification*, https://arxiv.org/abs/2608.28435 . It integrates structural domain constraints into robot-task formalization.
- **De Giacomo et al., AAAI 2014**, *Reasoning on LTL on Finite Traces: Insensitivity to Infiniteness*, https://doi.org/10.1609/aaai.v28i1.8872 . Finite/infinite semantics need explicit care.

This is a significant novelty **stop signal**. Prior sessions had already ruled out broad claims about semantic probes, conformal selective verification, and incomplete reference labels. These new sources further rule out the broad physical-grounding angle. We must avoid inventing a novelty claim from the combination.
