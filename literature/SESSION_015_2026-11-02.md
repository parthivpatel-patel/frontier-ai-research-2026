# Session 015 — Source-faithful scoring of recorded frontier-model outputs

Date: 2026-11-02 (US Eastern). **Research novelty: NOT established.** The main NL-to-formal paper is **not ready**.

## Meaningful advance

The previous session verified the schema and joinability of 7,224 recorded outputs. This session examined the upstream QSTRBench scoring implementation, built a standard-library-only replication of its strict set-equality scorer, added 12 new no-network tests, and successfully ran it on the pinned public source files using free GitHub-hosted cloud compute.

The source code explicitly extracts the first nonblank line after the last `answer:` marker (or the final nonblank line), removes parenthesized content, extracts relation tokens, then compares *sets* of predicted and reference relations. This is a syntactic exact-set score, **not** a physical truth or semantic faithfulness oracle. The upstream parser's greedy regex interprets compact `A!=B` as `=`; this was caught by a deliberately strict regression test. The first CI attempt failed because the test assumed the more intuitive `!=` interpretation. We corrected the test to preserve upstream behavior, not silently change the benchmark scoring rule. No claim is made that this edge case affects the actual benchmark scores.

## Literature and novelty audit

- QSTRBench (Cohn and Blackwell, 2026) already provides the dataset, model results and exact-set evaluation. **Reproducing its scores is replication, not a novel benchmark.**
- Li, Hogg and Cohn (2024), https://arxiv.org/abs/2405.15064 , already study logic-based evaluation under multiple plausible spatial interpretations.
- English et al., *VLTL-Bench* (2025), https://arxiv.org/abs/2507.00877 , already use trace-grounded evaluation of temporal-logic translation.
- Bisharat et al., *TLA+-Bench* (2026), https://arxiv.org/abs/2607.23425 , already demonstrate evaluation sensitivity in formal-specification generation.
- Beer et al. (2001), https://doi.org/10.1023/A:1008779610539 , and Kupferman and Vardi (2003), https://doi.org/10.1007/s100090100062 , establish vacuity as classical prior art.

These works preclude novelty claims based only on parsing, multiple valid answers, physical constraints, vacuity or trace selection. We still have **no defensibly new theoretical result or validated model improvement**.
