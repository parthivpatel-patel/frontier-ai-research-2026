## 1. Scientific decision: the 30-source pilot gate cannot support a 5% safety claim

The previous [source-disjoint gate](../experiments/PROTOCOL_016_SOURCE_DISJOINT_EVALUATION_GATE.md) specified 30 independent original sources as a practical *pilot minimum*, without a precision calculation. This session supplies the missing feasibility arithmetic in [pre-implementation Protocol 017](../experiments/PROTOCOL_017_SOURCE_LEVEL_PRECISION_GATE.md).

For n independent, identically distributed source-level Bernoulli outcomes, if zero accepted-source failures are observed, the exact **one-sided** 95% binomial upper bound is U = 1 - 0.05^(1/n). This is a classical exact-binomial calculation, **not a new theorem**. The event is deliberately conservative: a source is counted as failed if **any** accepted formula from that source is independently judged incorrect. Repeated outputs never increase the independent denominator.

| Hypothetical accepted independent sources, zero observed source failures | One-sided 95% upper bound |
| ---: | ---: |
| 4 | 52.71292% |
| 15 | 18.10363% |
| 30 | 9.50339% |
| 59 | 4.95076% |
| 299 | 0.99691% |

To get a bound at or below 5% even with zero failures, at least **59 accepted independent sources** are needed; to get at or below 1%, at least **299** are needed. With hypothetical 50% source acceptance, 59 accepted sources require 118 eligible independent sources if exactly half are accepted. These are **design requirements, not observed model outcomes, power for a method comparison, or a safety certification**.

The existing NL2MTL collection has only four original documents, so its 20 output files and 98 formulas cannot satisfy the independent-source denominator. Its source-level labels are also not independently adjudicated.

## 2. Code and falsification safeguards

The new [source_precision_gate.py](../src/source_precision_gate.py) computes exact zero-failure bounds and minimum accepted-source counts with numerically stable `log1p`/`expm1`, checks boundary minimality, and collapses repeated rows by original source. Its [synthetic-only tests](../tests/test_source_precision_gate.py) cover precision calculations, invalid inputs, source pseudoreplication, abstain-all behavior, missing adjudication, and multiple outputs from the same source. A new existing-workflow step prints hypothetical planning numbers without model inference or downloads.

If even one accepted source fails, the implementation **does not** misuse the zero-failure formula; it returns an undefined upper bound pending a separate exact interval procedure. It also refuses to treat zero accepted sources as zero risk.

## 3. Literature audit: closer methodological overlap

- **Andresel et al., LTLGuard (March 5, 2026):** constrained compact-language-model generation with lightweight formal consistency checks and refinement. https://arxiv.org/abs/2603.05728 . This must be treated as a relevant generation/checking baseline; a formal-checking pipeline alone is not new.
- **Fahim, Lagoa and Meira-Góes, Learning Linear Temporal Specifications from Demonstrations with Uncertainty (July 12, 2026):** LTL learning with uncertain traces and pseudo-Boolean optimization. https://arxiv.org/abs/2607.10918 . Its input setting differs from natural-language translation, but uncertainty-aware formal learning is already established.
- **SCP-NL2TL (August 2026):** calibrated selective translation with back-translation and semantic dispersion. https://arxiv.org/abs/2608.05439 . Selective acceptance and abstention are not novel by themselves.
- **Clopper–Pearson (1934):** exact binomial confidence limits are standard prior art; this session is a design-validity improvement, not a mathematical contribution.
