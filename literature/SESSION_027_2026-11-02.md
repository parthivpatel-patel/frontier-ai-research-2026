The code changes no LTL operator, parentheses, scope or non-proposition token. It only canonicalizes whole proposition IDs when all upstream mapping fields match exactly and canonical action and argument fields are nonempty. Invalid or missing mappings and undeclared symbols fail closed. The four unresolved mismatches need independent semantic analysis and must not be called model errors solely because their strings differ.

## Mathematics and epistemic boundary

Let I be a trace interpretation of propositions, and suppose two symbols p and q have I(p,t) = I(q,t) for every time t. Substituting p for q anywhere in an LTL formula preserves satisfaction, by structural induction on the formula. This is standard propositional substitutivity, not a new theorem. Our test observes only **equality of recorded grounding dictionaries**, not independently verified equality of the intended physical predicates. Consequently the 11 additional agreements are *conditional on the upstream metadata*.

An important experimental distinction follows: a post-hoc evaluator may use the reference and grounding dictionary to characterize benchmark sensitivity, but a deployed verifier or a head-to-head research method must not receive reference formulas, hidden correctness labels or trace oracles. Protocol 022's oracle firewall remains essential.

## Novelty and closest prior art

English et al., [VLTL-Bench](https://arxiv.org/abs/2507.00877) (2025), already identify the gap between lifted translation and grounded verification. Wang et al., [ConformalNL2LTL](https://arxiv.org/abs/2504.21022) (2025), already address calibrated translation reliability. Wang et al., [SCP-NL2TL](https://arxiv.org/abs/2608.05439) (2026), already combine semantic verification, repeated translations and selective risk control. Our alias sensitivity diagnostic does **not** establish a new algorithm or a defensible independent paper contribution.

## Falsification and next steps

1. A source-independent human adjudicator must verify whether repeated proposition labels actually refer to the same intended event; metadata identity alone is insufficient.
2. Establish provenance, permissions and independent source-family identities for stored predictions. Public GitHub access does not establish redistribution rights.
3. Freeze a source-disjoint, blinded experiment comparing the proposed physics-assumption uncertainty method with ConformalNL2LTL, SCP-NL2TL and formal model-checking baselines, using the same input and acceptance budget.
4. Measure unsafe acceptance and abstention at matched coverage; count independent source families, not generated rows. Reject a superiority claim if the advantage vanishes after grouping, label adjudication or changing physical assumptions.
5. If the above evidence is unavailable, prepare a transparent negative/methodological report rather than a speculative novelty claim.
