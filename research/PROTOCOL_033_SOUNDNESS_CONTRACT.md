# Protocol 033 — Soundness contract for physics-constrained temporal verification

Status: mathematical design note, **not** an empirical result or novelty claim. 2026-11-03.

## Problem and semantic boundary

Let (S) be a set of physical states, (I\subseteq S) the initial states, (T\subseteq S\times S) the true transition relation, and (L:S\to 2^{AP}) a proposition labeling. Let (\mathcal T(I,T,L)) denote the proposition traces generated by the system under explicitly specified finite or infinite semantics. A proposed physical constraint constructs an admissible trace set (C). For an LTL property (\varphi), a constrained checker searches (C\cap\neg\varphi), where the notation abbreviates the traces that violate the property.

**Soundness requirement for proving absence of physical counterexamples:** (\mathcal T(I,T,L)\subseteq C). If the constrained checker exhaustively finds no violating trace in (C), then there is no violating physical trace. If (C) is an *underapproximation*, a zero-counterexample outcome is inconclusive.

**Counterexample validity requirement:** Any reported counterexample must be independently checked for membership in (\mathcal T(I,T,L)). An overapproximation may yield spurious counterexamples. A validator that only checks trajectories from a sampled grid establishes neither inclusion nor completeness.

For bounded finite traces, all claims must specify horizon (H), initial-state domain, transition assumptions, and finite temporal-operator semantics. Infinite lasso semantics cannot be silently substituted for constant-velocity position trajectories.

## Minimal falsification witness

Let (P(x)=[x\geq0]) and (Q(x)=[x\geq1]). (Q\Rightarrow P) is valid for every real (x), but (P\Leftrightarrow Q) is false at (x=0). Consider the one-state finite physical trace (x_0=0,v_0=0). A constraint that incorrectly asserts (P=Q) excludes this physical trace. Any claim that the two propositions are universally equivalent under that constraint is therefore unsound. This witness is a constructed logical counterexample, not an observed language-model failure.

## Three-valued reporting rule

For each candidate specification and constraint, report one of:
- **Verified within stated domain** only when exhaustive checking and the physical-trace inclusion argument both hold.
- **Falsified by validated physical trace** only when the independently audited witness violates the property.
- **Inconclusive** otherwise, including incomplete search, unknown inclusion, failed oracle agreement, or unverifiable provenance.

Do not convert inconclusive into verified. Distinguish precision (fraction of reported counterexamples that are physical) from completeness (whether all physical counterexamples are represented); a finite sample cannot estimate universal completeness without sampling assumptions.

## Mandatory comparisons and failure gates

1. Unconstrained Boolean traces, with the same temporal semantics and horizon.
2. Exact transition-constrained enumeration over a bounded, fully specified state domain.
3. Sound overapproximate predicate abstraction, with explicit refinement of spurious witnesses.
4. Incorrect proposition-identity constraints as a negative control.
5. An independently implemented arithmetic/temporal oracle, with disagreements saved as minimal reproducible witnesses.

Record wall time and state counts only from actual runs, with hardware and cloud-run identifiers. Preregister denominators, seeds where applicable, and cases excluded for unsupported semantics. Reject the research hypothesis if the new method hides any valid physical counterexample, if its claimed improvement vanishes against a matched baseline, or if apparent gains depend on invalid constraints.

## Closest prior-art families to audit before a novelty claim

Classical automata-theoretic LTL model checking (Vardi/Wolper), counterexample-guided abstraction refinement (Clarke et al., 2000), predicate abstraction (Graf/Saidi, 1997), timed automata (Alur/Dill, 1994), and signal temporal logic and robustness (Maler/Nickovic, 2004) already address major parts of this problem. Compare formal assumptions and guarantees, not just terminology. A literature-search table with verified bibliographic records and newer neural-symbolic specification methods is still required. No priority or novelty claim is made here.

## Cloud-only execution gate

The existing standard-library experiments are candidates for GitHub-hosted runners, but **do not trigger any workflow** until repository visibility, account-level Actions usage/remaining allowance, spending limit, and payment requirements are verified. A public repository does not by itself prove a specific account has a zero-cost executable allowance. Do not run on the user's laptop. Preserve workflow URL, commit SHA, exact command, logs, JSON output, and independent oracle agreement once a run is authorized and confirmed free.

## Publication gate

Before a public manuscript: provide a proof or explicit bounded qualification of the inclusion property, executable independently validated comparisons, a reproducible artifact manifest, a verified closest-prior-art matrix, limitations, and accurate AI-assistance disclosure under the target venue's policy. The November 22 target is conditional, not a scientific deadline overriding these requirements.
